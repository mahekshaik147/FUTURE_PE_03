# FUTURE_PE_03

AI SEO Blog & Content Cluster Generator for Business Websites

*Future Interns – Prompt Engineering Task 3*

## Business Selected

**Skyline Properties – Real Estate Agency in Bangalore**

## Project Objective

This project demonstrates how Prompt Engineering can be used to generate SEO-optimized blog content and content clusters for business websites.

The system is designed to create:

* SEO blog outlines
* Long-form blog content
* Content clusters
* Internal linking strategies
* Local SEO-focused content
